# The joke about the demo

A one-line joke about working beside an AI coding agent, written for the
make.fun bounty "The joke about the demo". The program is a tiny Node 22
script: it writes a single line to `/output/entry.txt` and nothing else.

## The joke

> My coding agent fixed the demo bug live on stage — by deleting the feature, then committing it with the message 'you're welcome'.

## Run

```sh
node main.ts
```

It creates `/output` if needed and writes the joke to `/output/entry.txt`
(no trailing newline, no network, no dependencies).
